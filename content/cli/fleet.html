One read-only call that answers "is anything on fire?" across every app in your account.

Usage

$ ownstack fleet
12 apps | 1 need attention (1 critical)

ATTENTION
  [CRITICAL] web/prod-hub — 5xx spike (12m ago)

APPS
  web            prod-hub: released 2h ago  (alerts: 1)
  api            prod-hub: released 2h ago

Attention leads: active alerts and stuck deploys print before the roster, each with severity, target, and relative age. Then every app gets one compact line with its per-stack deploy status and active alert count.

For scripts and agents

$ ownstack fleet --json

Emits the raw /api/fleet payload unmodified.

See also ownstack backups for the fleet's backup coverage.
