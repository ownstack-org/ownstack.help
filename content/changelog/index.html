Notable changes across the OwnStack control plane, CLI, and docs. Newest first.

2026-11

  • CLI 2026.11.19.3: cluster destroy, developers delete, llm destroy, voice destroy, pg backups:restore and pg backups:delete ask you to type the name or id back. Pass --yes in scripts.
  • CLI 2026.11.19.2: --help on any subcommand prints help and never runs the command. stack destroy refuses when it cannot load the stack to confirm its name.
  • CLI 2026.11.19.1: the default control plane is https://api.ownstack.org everywhere; the Rails template no longer ships TLS keys.
  • Install: curl -fsSL https://ownstack.org/install.sh | bash installs the compiled CLI and checks its sha256 against the Homebrew formula. If you installed with curl before November 19, rerun it.
  • Billing: OwnStack uses prepaid usage credits (500,000 credits = $1). See Billing.
  • Scaling: ownstack app scale APP web=2 worker=1 sets process counts and keeps them across deploys. See Scaling processes.

2026-05

  • CLI: ownstack db dump streams a Postgres or MySQL dump to a local file. Auto-detects type.
  • Docs: ownstack.help launched. The site you're reading.

Subscribing

Run brew upgrade ownstack or rerun the install one-liner to get the latest CLI. The docs commit feed shows every docs change.
